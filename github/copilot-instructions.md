# Copilot Project Instructions

This project is a graduation project for a Real-Time Vietnamese Sign Language Recognition and Translation System.

## Main specification
Read and follow `docs/BUILD_PLAN.md` as the main project specification.

## Mandatory rules
1. Work phase-by-phase. Start with Phase 0.
2. Do not implement later phases before the current phase is verified.
3. Before changing files, inspect the existing project structure and code.
4. Do not delete or rewrite working code unnecessarily.
5. Keep class labels and hyperparameters configurable.
6. Use the same preprocessing logic during training and inference.
7. Do not assume that an ASL dataset represents Vietnamese Sign Language.
8. Before integrating any dataset, report its license, classes, format, and suitability.
9. Handle missing detections and runtime errors gracefully.
10. Add verification/tests for important modules.
11. Do not claim a feature works unless it has been tested.
12. When an error occurs, show the exact cause and fix it rather than hiding it.
13. Keep README.md updated after each completed phase.

## Current task
Begin with Phase 0 only:
- inspect the current workspace;
- create the initial project structure;
- create requirements.txt;
- create a basic README.md;
- verify the Python virtual environment;
- do not build the AI model yet;
- do not download a dataset yet.

After Phase 0, stop and report what was created, what was tested, and any remaining issues. Wait for approval before moving to Phase 1.
