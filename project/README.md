# Sign Language AI — Phase 0

This repository contains the Phase 0 skeleton for the Real-Time Vietnamese Sign Language project.

See the root build plan for full specification: ../BUILD_PLAN.md

Phase 0 deliverables:
- Project skeleton
- `requirements.txt` with recommended packages
- Basic config template
- Directories for data, models, checkpoints, and outputs

Do not proceed to Phase 1 without approval.

Dataset Status (Phase 1 - research)
- A Phase 1 dataset research summary has been created at `docs/DATASET_RESEARCH.md`.
- Shortlist: VSL400 (Zenodo) and a processed VSL corpus on Kaggle (VSL - Cropped) are primary candidates for investigation. Both require license/provenance checks before downloading or redistributing.

Do not download or integrate datasets until approvals and Data Usage Agreements are in place.
